Features

核心能力

一个用于学习 Redis 内部原理的服务器实现，覆盖网络层、协议层、存储层与内存管理。

高性能网络通信

基于 Java NIO 的非阻塞 I/O 与事件循环架构，支持 TCP 拆包 / 粘包处理，高效应对多客户端连接。

SelectorServerSocketChannelevent loop

RESP 协议解析

完整实现 Redis 序列化协议的解析与响应格式化，支持简单字符串、错误、整数与批量数据。

RespUtil+OKbulk string

多数据库支持

内置 16 个相互独立的数据库，通过 SELECT 命令切换，模拟真实 Redis 的存储布局。

SELECTdb 0..15

多样化数据结构

字符串、基于压缩列表的 List、基于跳表的 ZSet，并根据数据规模动态切换底层编码。

ZipListScoredSkipListembstr

内存淘汰策略

实现 LRU、TTL、随机淘汰等多种策略，在内存达到阈值时按规则清理键值数据。

LRUTTLrandomno-eviction

事务支持

支持 MULTI / EXEC / WATCH / DISCARD 基本事务命令，维护命令队列并批量执行。

MULTIEXECWATCH

Architecture

核心组件

小而清晰的模块划分，每个文件对应 Redis 的一个关键子系统。

JavaRedisServer

服务器主类：监听端口、管理多个数据库实例、处理客户端连接，并实现事件循环与内存淘汰调度。

46 KBevent loopeviction

RespUtil

RESP 协议工具类，负责协议解析与响应数据格式化，是客户端与服务器之间的协议边界。

parseserialize

ZipList

压缩列表实现，用于存储小型列表数据，支持头尾插入与遍历，模拟 Redis 的 ziplist 编码。

ziplistsmall list

ScoredSkipList

基于分值的跳表，支撑有序集合 ZSet 的高效插入、删除、查找与范围查询。

skiplistzsetrange query

Multi

事务处理模块，维护命令队列并支持 WATCH / DISCARD 等事务语义。

MULTIEXECWATCH

RedisConstants

集中管理命令名称、淘汰策略与协议常量，避免魔法字符串散落各处。

constantsprotocol
Eviction

内存淘汰策略

当内存达到上限时，按预设规则回收键值空间。

VOLATILE_LRU VOLATILE_TTL VOLATILE_RANDOM ALLKEYS_LRU ALLKEYS_RANDOM NO_EVICTION
Quick Start

快速开始

编译并启动服务器，然后用测试客户端连接验证。

启动服务器
# 编译服务器主程序
javac org/bytefly/JavaRedisServer.java

# 启动服务器（默认监听 6379）
java org/bytefly/JavaRedisServer
运行测试客户端
# 编译测试客户端
javac org/bytefly/SimpleRedisClient.java

# 连接并验证 SET / GET / SELECT
java org/bytefly/SimpleRedisClient
